## Repository Nature

This is an **educational lab document** (实验3.md) about Spark RDD programming, not a software project. The directory contains:

- `实验3.md` - Lab guide covering Spark RDD data sources, transformations, actions, and WordCount实例
- `实验3_images/` - Screenshots referenced in the lab document
- `result/` - Result images from Spark command execution

- Spark RDD internal/external data sources
- RDD transformations: map, flatMap, filter, distinct, union, intersection, subtract
- RDD actions: collect, count, countByValue, take, top, reduce, foreach
- WordCount实例: end-to-end example counting words in /etc/profile
