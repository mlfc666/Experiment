Spark Streaming 应用：计算电商商品关注度

实验简介

使用Spark Streaming构建实时数据计算系统，通过使用java socket编程模拟用户浏览商品信息时产生的数据，使用Spark Streaming应用实现基本功能。

实验目的

  • 掌握使用Java Socket编程
  • 掌握Spark Streaming的基本操作
  • 掌握Spark Streaming updateStateByKey的使用

实验内容

使用Spark Streaming构建实时数据计算系统，通过使用java socket编程模拟用户浏览商品信息时产生的数据，使用Spark Streaming应用实现基本功能，使用updateStateByKey进行结果累加计算，在Spark平台上运行。

学生可以在这个简单项目的基础上进行拓展，例如：将数据保存在Hadoop集群的HDFS上，还可以通过用户数据进行建模处理，建模型存储在HDFS上，进行用户商品推荐这个项目可以横向扩展。加上更多的模块，比如说Mlib。ALS算法进行用户商品推荐。在实际项目中通常是使用kafka来进行消息的传输。这里没有使用kafka了，使用了Socket来模拟数据传输，感兴趣的同学可以尝试使用kafka来作为数据传输。

实验知识点

  • Spark Streaming应用的基本实现
  • DStream的基本操作
  • updateStateByKey的使用

实验过程

实验中使用Scoket来模拟用户浏览商品产生的实时数据，模拟生成数据的程序在本实验的附件中，包含源代码和可以执行的jar包，产生的实时数据包括以下几项：

  • 商品ID
  • 该商品被浏览的次数
  • 停留时间
  • 是否收藏该商品
  • 购买次数

格式示例：

商品ID-20::4::7.372579::-1::0
商品ID-132::1::7.238897::0::2
商品ID-78::4::7.2234173::0::0

使用Spark Streaming构建实时数据处理程序，实时读取，实时计算商品的关注度。

商品关注度计算规则：设定浏览次数的权重为0.8，浏览时间权重为0.6，是否收藏和购买力度都为1。通过关注度的数值排名，从而发现当前电商平台最受人们关注的商品。

代码思路

  • 首先初始化StreamingContext：
xxxxxxxxxx
//AppName 自然就是当前Job的名字，Master就是Spark的主机地址，这里采用的是本地模式 
SparkConf sparkConf = new SparkConf().setAppName("StreamingGoods").setMaster("local[3]"); 
// 新建JavaStreamingContext对象，new Duration(5000) 窗口时间，单位毫秒 
JavaStreamingContext jsc = new JavaStreamingContext(sparkConf, new Duration(5000)); 
//把数据保存到对应的路径下 
jsc.checkpoint(checkpointDir); 
//获取模拟数据，设置服务端地址和端口号 
JavaReceiverInputDStream<String> jds = jsc.socketTextStream("127.0.0.1", 9999); 
//定义字符串，保存数据 
JavaDStream<String> mess = jds.map(str -> str); 
mess.print();
  • 数据处理：商品关注度计算，约定浏览次数的权重为0.8，浏览时间权重为0.6，是否收藏和购买力度都为1。
xxxxxxxxxx
//mapToPair就是将rdd转换为键值对rdd,与map不同的是添加了一个key 
JavaPairDStream<String, Double> splitMess = jds.mapToPair(line -> { 
    String[] lineSplit = line.split("::"); 
    Double followValue = Double.parseDouble(lineSplit[1]) * 0.8 + Double.parseDouble(lineSplit[2]) * 0.6 + Double.parseDouble(lineSplit[3]) * 1 + Double.parseDouble(lineSplit[4]) * 1; 
    return new Tuple2<>(lineSplit[0], followValue); 
});
  • 更新关注度值：使用updateStateByKey进行结果累加计算。在这里是通过updateStateByKey来以Batch Interval为单位来对历史状态进行更新，在这里需要使用checkPoint,用于保存父RDD的值。在Spark1.6.X之后也可以尝试使用mapWithState来进行更新值。
xxxxxxxxxx
//使用updateStateByKey来进行操作。在这里是通过updateStateByKey来以Batch Interval为单位来对历史状态进行更新， 
JavaPairDStream<String, Double> UpdateFollowValue = splitMess.updateStateByKey((newValues, statValue) -> { 
    Double updateValue = statValue.or(0.0); 
    //循环遍历，更新value值 
    for (Double value : newValues) { 
        updateValue += value; 
    } 
    //返回更新的值 
    return Optional.of(updateValue);
});
  • 结果输出：并将里面的商品进行关注度排序，降序排序，只显示关注度最高的十个商品。实现思想，由于原RDD UpdateFollowValue的值可以知道是的形式，我们使用sortByKey是不能这样进行排序的，因为它并不是按照关注度排序。我们需要将其转化为的形式，然后再按照sortByKey来进行排序，然后进行输出。
xxxxxxxxxx
// 我们需要将其转化为的形式，然后再按照sortByKey来进行排序，然后进行输出 
UpdateFollowValue.foreachRDD(followValue -> { 
    JavaPairRDD<Double, String> followValueSort = followValue.mapToPair(valueToKey -> new Tuple2<>(valueToKey._2, valueToKey._1)).sortByKey(false); 
    List<Tuple2<String, Double>> list = followValueSort.mapToPair(arg0 -> new Tuple2<>(arg0._2, arg0._1)).take(10); 
    //遍历商品关注度，打印输出 
    for (Tuple2<String, Double> tu : list) { 
        System.out.println("商品ID: " + tu._1 + " 关注度: " + tu._2); 
    } 
});

public class StreamingGoodsAnalysis implements Serializable {
    private static final long serialVersionUID = 1L;
