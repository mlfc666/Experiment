Spark 本地开发说明

实验目的

  • 掌握 IntelliJ IDEA 新建工程的基本过程
  • 掌握 IntelliJ IDEA 新建类的基本过程
  • 掌握 IntelliJ IDEA 工程打包
  • 掌握上传文件

实验内容

针对 IntelliJ IDEA、XFTP 工具，文件上传与下载功能学习

实验知识点

  • IntelliJ IDEA 新建工程的基本使用
  • IntelliJ IDEA 新建 scala 类和 java 类的基本使用
  • IntelliJ IDEA 工程打包的基本使用
  • 使用 XFTP 上传下载文件的使用

实验环境

软件环境：

IntelliJ IDEA2017.3

JDK1.8

开发环境、工具：

CentOS 7

IntelliJ IDEA

实验过程

1.通过 IntelliJ IDEA 工程创建工程；

2.在工程创建 scala 类以完成部署开发项目代码；

3．完成代码开发后，将工程整体打包为 jar，以满足代码在服务器执行；

4．采用 FTP 工具，将工程 jar 上传到腾讯云环境。

安装IntelliJ IDEA

下载地址：https://www.jetbrains.com/idea/download/#section=windows

选择社区版下载

下载完成后，双击安装，均选择默认设置，点击下一步，即可完成安装

工程创建

  • 在菜单栏点击 File>>New>>Project 新建项目，左侧选择 Maven，在右侧点击 New，选中本机安装的 JDK 的目录，然后点击 Next

  • 在新弹出的窗口中，给项目命名后，点击 Finish

配置 scala 类的运行环境

  • 在左侧项目目录 src 下的 main 目录上右键，选择 New>>Directory,输入“scala”,回车，创建scala文件夹。

配置 Scala 插件

配置一次即可，后续项目可通用，不用重复配置

点击“File --> Settins”，在 Plugins 中搜索 Scala 并安装（Install），安装完成后，出现“Restart IDE”按钮， 点击 Restart IDE，重启 IDE 环境。

配置 Scala SDK

点击“File --> Project Structure ”,在 Libraries 视图，点击加号“+”，配置 Scala SDK。

注：如果本地没有安装过 Scala SDK ，可以酌情选择 Download 按钮进行下载安装Scala2.11 版本 ，但十分不建议这么做！因为 IDEA 会自动下载最新版 Scala2.13 版本，该版本与其他的实验开发环境不匹配，有极高概率会发生错误！

  • 点击“OK”完成项目环境配置

配置 Lambdas ，并将 scala 文件夹设置为 Sources

点击“File --> Project Structure ”,在 Modules 视图中设置 Language Level 为 8-Lambdas，并将 scala 文件夹设置为 Sources，点击ok。

scala 中添加包

  • 在 scala 文件夹上点击右键，new>>package,添加一个 package，命名为 com，按 Enter 回车，完成项目环境配置。

配置 java 类的运行环境

配置编译版本

点击 左上角菜单 File --> Setting，找到Build, Execution,Deployment>Compiler>Java Compiler配置项，将Per-module bytecode version设置为8。

配置 Lambdas

点击“File --> Project Structure ”,在 Modules 视图中设置 Language Level 为 8-Lambdas， type annotation etc，点击ok。

java 中添加包

  • 在 java 文件夹上点击右键，new>>package,添加一个 package，命名为 com，按 Enter 回车，完成项目环境配置。

如果 Java 和 scala 同时存在

按上述步骤分别在java和scala文件夹下创建com包，完成环境配置。

服务器端运行

工程打包(生成 jar 文件)

有两种生成 jar 包方法，推荐使用 6.8.1 的 Maven 生成 jar 包方法，理由如下：

i. 瘦包不包含依赖 jar 包，体积较小，易于上传至服务器端，而胖包将 maven 项目中的依赖包和项目打为一个整个 jar 包，体积大，影响 ftp 传输效率；

ii. 瘦包不包含工程数字签名，易于直接运行，而胖包中包含工程的数字签名，易导致数字签名的验证错误，影响程序正常运行。

Maven 生 jar 包方法

1.点击 Maven 工作栏，打开 Maven 视图；

2.依次打开“工程名”>>Lifecycle，鼠标双击 package 开始打包，等待打包过程完成；

  1. 查看 jar 包位置，左侧 Project 工作栏的 target 文件夹下即可找到本项目jar 包；

4.在 jar 包上右键，选择 “show in explorer ”,可以查看该 jar 在硬盘中的具体位置，在上传服务器时，会用到这个文件路径。

生成胖包方法

  1. 点击 file --Project Structurce；

  1. 点击 Artifacts ，再点击 “+ ”，选择JAR->From modules with dependencies...；

  1. 弹出窗口后选择对应模块，选择运行主类，点击 ok，继续 ok 完成；

 

  1. 点击Build->Build Artifacts...；

  1. 选择 build 构建，等待完成；

  1. 查看 jar 包位置，在项目左侧 out 文件夹下即可找到 jar 包；

7.在 jar 包上右键，选择 “show in explorer ”,可以查看该 jar 在硬盘中的具体位置，在上传服务器时，会用到这个文件路径。
